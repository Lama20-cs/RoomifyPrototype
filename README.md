# Roomify 🏡

A **solo UI prototype** for a mobile interior design app, built with Flutter and Dart as a project in the “From Scratch to the Store” bootcamp, under the supervision of the TechnoRepos Community.

## About

Roomify is an interior design app concept that helps users explore room designs and furniture based on their room dimensions and personal preferences. This individual bootcamp project focuses on the **user interface and user experience**: the screens, layout, and visual style. I chose this idea because of my passion for interior design and my interest in combining creativity with technology.

## UI Screens

- Room type selection
- Room dimensions input
- Interior design styles
- Furniture and design recommendations

## Design

A warm, natural color palette inspired by cream, beige, brown, and natural wood, with a clean and simple layout.

## Technologies

- Flutter
- Dart
- AI tools for development assistance

## Status

An initial UI prototype that started as an onboarding screen task during the bootcamp and grew into a small app concept.

## Future Improvements

- More room types, design styles, and furniture options
- Personalized recommendations
- Improved room layout suggestions
